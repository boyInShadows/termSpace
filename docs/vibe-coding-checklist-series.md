# Vibe Coding Checklist editorial series

The seeded, published series has three ordered pieces: **Before You Prompt**, **Review the Diff**, and **Ship and Maintain**. Each uses the same structure: the decision, a short checklist, a verification step, and a relevant marketplace link. The links go through the Blog's `/marketplace/products/[slug]` redirect so each deployment can set its own marketplace origin with `MARKETPLACE_PUBLIC_URL`.

Staff may edit or unpublish each article in the Blog admin. The living dossier collects the sequence, resources, and new coverage; editors can maintain it under Tags & series. Reader perspectives are moderated and selected separately from comments. Seed is idempotent and leaves edits to existing articles untouched. Publishing to a deployed database requires running the repository seed there.
